## 关于我们

天机阁 (Fairy Oracle Sanctuary) 是一个开发者团体，致力于：
- **代码自由** - 我们倾向于使用 GPL/AGPL 等 Copyleft 许可证，确保软件赋予用户自由
- **以人为本** - 无论背景如何，我们重视每一位贡献者
- **纯粹热爱** - 我们分享创造，不设前提，不求回报

## 技术栈

- **框架**: [Next.js 16](https://nextjs.org/) (App Router, SSG)
- **语言**: [TypeScript](https://www.typescriptlang.org/)
- **样式**: [Tailwind CSS 4](https://tailwindcss.com/)
- **动画**: [Framer Motion](https://www.framer.com/motion/)
- **国际化**: [next-intl](https://next-intl-docs.vercel.app/)
- **图标**: [Lucide React](https://lucide.dev/)

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 部署

本网站通过 GitHub Actions 自动部署到 GitHub Pages。

1. 推送到 `main` 分支
2. GitHub Actions 自动构建并部署
